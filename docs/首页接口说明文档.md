# 首页接口说明文档

## 1. 导航菜单接口

### 1.1 获取主菜单列表

**接口路径**: `/api/navigation/main-menu`
**请求方法**: `GET`
**认证要求**: 可选
**描述**: 获取首页顶部导航栏的菜单列表

#### 请求参数

| 参数名 | 类型 | 必填 | 描述 | 默认值 |
|--------|------|------|------|--------|
| language | string | 否 | 语言代码 (zh-CN/en) | zh-CN |
| theme | string | 否 | 主题模式 (light/dark/system) | system |

#### 响应数据

```typescript
interface MenuItem {
  id: string;           // 菜单项唯一标识
  title: string;        // 菜单标题
  path: string;         // 菜单路径
  target?: '_blank';    // 打开方式
  icon?: string;        // 图标名称
  order: number;        // 排序号
  visible: boolean;     // 是否可见
}

interface MenuResponse {
  success: boolean;
  data: MenuItem[];
  timestamp: number;
}
```

#### 示例响应

```json
{
  "success": true,
  "data": [
    {
      "id": "menu-features",
      "title": "言启智云",
      "path": "/features",
      "order": 1,
      "visible": true
    },
    {
      "id": "menu-pricing",
      "title": "语枢未来",
      "path": "/pricing",
      "order": 2,
      "visible": true
    },
    {
      "id": "menu-about",
      "title": "深栈智启",
      "path": "/about",
      "order": 3,
      "visible": true
    },
    {
      "id": "menu-contact",
      "title": "万象归元",
      "path": "/contact",
      "order": 4,
      "visible": true
    }
  ],
  "timestamp": 1728921600000
}
```

## 2. 首页按钮接口

### 2.1 获取行动号召按钮信息

**接口路径**: `/api/navigation/cta-buttons`
**请求方法**: `GET`
**认证要求**: 可选
**描述**: 获取首页主要行动号召按钮的配置信息

#### 请求参数

| 参数名 | 类型 | 必填 | 描述 | 默认值 |
|--------|------|------|------|--------|
| location | string | 是 | 按钮位置 (header/main/footer) | - |
| language | string | 否 | 语言代码 | zh-CN |

#### 响应数据

```typescript
interface CTAButton {
  id: string;              // 按钮唯一标识
  text: string;            // 按钮文本
  action: string;          // 按钮动作 (url/function)
  target: string;          // 目标地址或函数名
  variant: string;         // 按钮变体 (primary/secondary/outline)
  size: string;            // 按钮尺寸 (sm/md/lg)
  icon?: string;           // 图标名称
  tracking?: string;       // 跟踪参数
  show: boolean;           // 是否显示
}

interface CTAButtonResponse {
  success: boolean;
  data: CTAButton[];
  timestamp: number;
}
```

## 4. API 调用示例

### 4.1 React 组件中使用导航菜单接口

```typescript
// components/navigation/HeaderMenu.tsx
import { useEffect, useState } from 'react';

interface MenuItem {
  id: string;
  title: string;
  path: string;
  order: number;
  visible: boolean;
}

export const HeaderMenu = () => {
  const [menuItems, setMenuItems] = useState<MenuItem[]>([]);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    const fetchMenu = async () => {
      try {
        setLoading(true);
        const response = await fetch('/api/navigation/main-menu?language=zh-CN');
        const data = await response.json();
        if (data.success) {
          setMenuItems(data.data.filter(item => item.visible).sort((a, b) => a.order - b.order));
        }
      } catch (error) {
        console.error('Failed to fetch menu:', error);
      } finally {
        setLoading(false);
      }
    };

    fetchMenu();
  }, []);

  if (loading) {
    return <div className="loading-placeholder">Loading...</div>;
  }

  return (
    <nav className="hidden md:flex items-center space-x-6">
      {menuItems.map(item => (
        <a
          key={item.id}
          href={item.path}
          className="text-white/80 hover:text-white transition-colors"
        >
          {item.title}
        </a>
      ))}
    </nav>
  );
};
```

### 4.2 获取CTA按钮数据示例

```typescript
// hooks/useCTAButtons.ts
import { useState, useEffect } from 'react';

interface CTAButton {
  id: string;
  text: string;
  action: string;
  target: string;
  variant: string;
  size: string;
  icon?: string;
  show: boolean;
}

export const useCTAButtons = (location: string) => {
  const [buttons, setButtons] = useState<CTAButton[]>([]);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    const fetchButtons = async () => {
      try {
        setLoading(true);
        const response = await fetch(`/api/navigation/cta-buttons?location=${location}`);
        const data = await response.json();
        if (data.success) {
          setButtons(data.data.filter(btn => btn.show));
        }
      } catch (error) {
        console.error('Failed to fetch CTA buttons:', error);
      } finally {
        setLoading(false);
      }
    };

    fetchButtons();
  }, [location]);

  return { buttons, loading };
};
```

## 5. 错误处理规范

### 5.1 统一错误响应格式

所有API接口应返回统一的错误响应格式：

```json
{
  "success": false,
  "error": {
    "code": "ERROR_CODE",
    "message": "错误描述",
    "details": {}
  },
  "timestamp": 1728921600000
}
```

### 5.2 常见错误码

| 错误码 | 描述 | HTTP状态码 |
|--------|------|------------|
| UNAUTHORIZED | 未授权访问 | 401 |
| FORBIDDEN | 禁止访问 | 403 |
| NOT_FOUND | 资源不存在 | 404 |
| BAD_REQUEST | 请求参数错误 | 400 |
| INTERNAL_ERROR | 服务器内部错误 | 500 |

## 6. 性能优化建议

1. **缓存策略**：对导航菜单和静态内容使用本地缓存，设置合理的过期时间
2. **响应式加载**：根据设备类型加载适合的资源大小
3. **预加载**：对首屏关键资源进行预加载
4. **CDN分发**：使用CDN加速静态资源访问

## 7. 安全注意事项

1. **输入验证**：所有API输入参数必须经过验证
2. **XSS防护**：对用户输入的内容进行转义和过滤
3. **CSRF保护**：关键操作需要CSRF令牌验证
4. **Rate Limiting**：实施接口调用频率限制，防止恶意请求
